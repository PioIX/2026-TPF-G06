# Proyecto-Final
# Presupuesto y Documento de Alcance

### Descripción del proyecto
*Nombre de la aplicación:* “Fast Food Rush”
*Descripción general:* Va a ser un juego de crear comida rápida, como hamburguesas y papas fritas
*Problemática o necesidad que aborda:* Armar la comida en tiempo, atender a los clientes y que no se te queme nada
*Público objetivo:* Niños y adolescentes
*Objetivo general:* Aprender a armar hamburguesas
*Principales funcionalidades:* Armar hamburguesas

### Alcance
Funcionalidades desarrolladas
- Registro e inicio de sesión (correo/contraseña). 
- Botón de "Deshacer / Reiniciar" para quitar ingredientes si el jugador se equivoca 
- Generador de pedidos aleatorios que indican qué hamburguesa o combo 
- Sistema de validación que compara la hamburguesa armada con el pedido objetivo y otorga puntos al acertar. 
- Temporizador de tiempo límite para entregar cada pedido. 
- Contador de puntaje en tiempo real y registro del ranking 
- Botón de reiniciar partida.

### Principales características esperadas del producto final
- Código estructurado mediante componentes reutilizables (ej: <Ingrediente/>, <Plato/>, <Pedido/>, <Marcador/>).
- Manejo del estado del juego con useState y useEffect (para el tiempo, puntaje y capas de la hamburguesa).
- Guardado automático del puntaje máximo en el navegador para que no se pierda al recargar la página.
- Estilos visuales llamativos y aptos para juegos, adaptados para jugarse desde una computadora o celular.
- Animaciones sencillas al agregar ingredientes o completar un pedido.
